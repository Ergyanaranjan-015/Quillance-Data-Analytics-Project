# E-Commerce Sales, Customer Churn & Supply Chain Analytics

## Project Overview
This project analyzes e-commerce sales performance, customer purchasing behavior, product profitability, and regional business performance using Python, SQL, and Power BI.

## Objectives
- Clean and transform transactional data.
- Analyze sales, profit, and regional performance.
- Perform customer segmentation using RFM analysis.
- Build an interactive Power BI dashboard.
- Provide actionable business recommendations.

## Tools & Technologies
- Python
- Pandas
- SQL
- SQLite
- Google Colab
- Microsoft Power BI

## Dataset Overview
- Total Records: 9,994
- Unique Customers: 793
- Unique Orders: 5,009
- Unique Products: 1,862

## Key Business Results
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Total Quantity: 37,873
- Profit Margin: 12.47%

## Customer Segmentation
RFM analysis identified six customer segments:
- Champions
- Loyal Customers
- At Risk
- Inactive Customers
- Recent Customers
- Potential Customers

## Dashboard
The Power BI dashboard includes sales, profit, customer, and profit margin KPIs, along with category, regional, and monthly sales analysis.

## Business Recommendations
- Improve Furniture profitability.
- Retain Champions and Loyal Customers.
- Re-engage At Risk customers.
- Review regional performance.
- Monitor high-discount transactions.

## Project Limitations
- Product cost data was unavailable for cost-based gross margin analysis.
- Returns data was unavailable for return-rate analysis.
- RFM inactivity is a potential churn indicator, not confirmed churn.
